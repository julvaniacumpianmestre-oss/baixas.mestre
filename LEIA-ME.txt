ARQUIVOS PARA BANCO PERSISTENTE - SISTEMA DE BAIXAS

1. Substitua app.py no GitHub por este arquivo.
2. Substitua requisitos.txt.
3. O Dockerfile incluído pode substituir o atual se desejar manter tudo igual ao pacote.
4. Mantenha o index_v10.html V11.3 já publicado.
5. No Render, crie/conecte um PostgreSQL e adicione a variável DATABASE_URL ao Web Service.
6. Faça Deploy latest commit.
7. Teste /health. Deve retornar banco: conectado.
8. Grave uma atualização, abra uma nova janela e clique em Abrir última atualização.

Sem DATABASE_URL, o sistema usa SQLite somente como fallback local e NÃO deve ser considerado persistente no Render Free.
